# 实机验证实验报告资料包

本资料包面向负责撰写实验报告的组员，集中整理 RoboMaster EP 桌面物体自动分类项目的实机部分材料。建议先阅读本文件和《报告撰写建议.md》，再查看主程序说明、运行汇总和原始证据。

## 目录说明

- `01_实验要求`：课程实验要求原文。
- `02_核心程序与模型`：最终版主程序、配置、模型、测试和完整技术说明。
- `03_分阶段测试代码`：机械臂、六位置抓取和固定顺序测试版本，用于说明系统如何逐步联调。
- `04_完整运行记录`：主程序全部扫描图、事件日志和任务总结，包含成功、失败与中断调试记录。
- `05_图像与视频证据`：六格识别截图、双物体抓取原始录像、PPT内嵌剪辑素材及视频封面。
- `06_汇报材料`：现有汇报PPT和真机部分页面预览，可作为报告结构与插图参考。
- `07_报告辅助材料`：运行汇总、代码入口索引、测试结果、文件清单和哈希。

## 证据边界

- `六格同时识别结果.png`支持“一个画面中对六个固定区域同时进行识别并输出类别与置信度”。它不等于六件物体均完成实机抓取。
- 两个双物体视频文件支持“杯子和瓶子的双物体实机演示”。原始录像与PPT内嵌剪辑素材的编码帧率不同，汇报PPT还可能设置播放裁剪；报告截帧前应先确认采用哪个版本。不要将双物体演示扩展表述为六件连续抓取验收。
- `主程序运行汇总.csv`来自108份 `task_summary.json`。其中 `sorted_total` 表示程序复扫后源格被判为空并累计完成，不单独证明物体落入正确分类区。
- 全部运行记录来自连续开发和调参过程，条件并非统一，不能直接用作独立重复试验并计算正式成功率。
- 单元测试验证配置、路线逆序、状态机和联锁等程序逻辑，不等于连接真实机器人后的安全性或成功率验证。

## 已排除内容

为避免资料包臃肿和误用，本包未重复收录历史ZIP、缓存目录、`__pycache__`、Ultralytics运行缓存、离线安装wheel、PPT生成脚本和仿真专用工程。模型在核心程序和独立推理目录中各保留一份，便于组员直接运行对应入口。
