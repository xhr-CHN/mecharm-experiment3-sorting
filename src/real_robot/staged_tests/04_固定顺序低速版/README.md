# RoboMaster 固定六次抓取（G2 左放、其余右放、低速版）

这是新增的独立代码，不会修改、导入或覆盖原来的 `robomaster_sorter`。程序不启动摄像头视频流，不加载 YOLO/模型，不读取图像，也不进行类别识别或抓取结果识别。

## 固定执行顺序

```text
G2 -> 左侧
G5 -> 右侧
G1 -> 右侧
G4 -> 右侧
G3 -> 右侧
G6 -> 右侧
```

程序固定执行六轮；只有操作员中止、SDK 命令失败或超时才会提前停止。

## 保留的动作和停顿

- 每轮抓取前机械臂回中，使臂载摄像头回到原参考位，并等待 0.8 秒；
- 保留张开夹爪 1.5 秒、闭合夹爪 1.5 秒、闭合后停顿 0.4 秒；
- 每个底盘动作后等待 2 秒；
- 抓起和投放后机械臂回中；每轮结束后再次执行摄像头参考位归位并等待 0.8 秒；
- 正式执行前保留 5 秒安全倒计时。

## 速度变化

- 原程序平移速度为 `0.50 m/s`；本版本为 `0.35 m/s`；
- 原程序旋转速度为 `30 deg/s`；本版本为 `20 deg/s`。

RoboMaster SDK 的距离式 `chassis.move` 平移速度下限是 0.5 m/s，因此本版本的平移动作改为 `chassis.drive_speed` 的低速定时控制；每段结束都会立即发送停止命令，再执行原有的 2 秒停顿。该方式是开环计时，第一次真机运行必须清空六个格子并核对每段位移；如实际距离偏短或偏长，只调整配置中的路线距离或 `translation_speed_mps`，不要改变机械臂标定点。

## 运行

先只检查配置，不连接机器人：

```bash
python3 fixed_sequence_grasp.py --validate-config
```

只打印动作计划，不连接机器人：

```bash
python3 fixed_sequence_grasp.py
```

真机执行固定六次抓取：

```bash
python3 fixed_sequence_grasp.py --execute
```

依赖只有 RoboMaster SDK：

```bash
python3 -m pip install robomaster
```

## 真机首轮检查

1. 清空六个格子和左右投放路径，架空或抬起机械臂，先检查底盘低速路线。
2. 确认机器人上电原点与原程序完全一致。
3. 逐段确认 `0.35 m/s` 定时平移的实际距离；低速可以减轻打滑，但地面材质、电量和负载仍会影响开环距离。
4. 确认 G2 的低位抓取姿态适合左放物体，其余五格的高位姿态适合右放物体。
5. 现场保留安全员和物理急停。
